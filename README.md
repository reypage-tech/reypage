# Reypage｜GAS業務自動化

Google スプレッドシート、Gmail、フォーム、ドライブの手作業を、Google Apps Script で自動にします。

## 経歴
- R社（プライム上場企業）の営業組織で、他部署から依頼を受けてGASの仕組みを作り、運用まで担当しました
- 約3.5年、GASの仕組みを作って運用してきました。
- 自分で作った仕組みの一つは約2,700人が使い、1人あたり1日約1〜2時間の作業を減らしました

## 頼める仕事の例
- メールやフォームの内容をシートへ転記
- 集計と週次・月次レポート
- 担当者別・取引先別のPDF作成と保存
- 期限や未完了の通知
- 前の担当者が作ったGASの修正

## 料金の目安
- 小さな自動化：最短1日〜・1.5万円〜
- 標準：約1週間〜・5万円〜

## 進め方
内容を決める、作る、納品、納品後1か月の修正（無料）

## 見本（すべて架空のデータ）
- gas-tutor-payment-statement：報酬計算と講師別のPDF明細
- gas-mail-to-sheet-ledger：通知メールから台帳へ
- gas-monthly-pdf-by-person：日報を担当者ごとにPDF化
- gas-weekly-report-pdf：週次レポートの自動作成
- gas-form-automation-sample：フォーム回答の記録と毎朝のまとめ

サイト：https://reypage.pages.dev/automation/

---
Reypage builds Google Apps Script automation for Sheets, Gmail, Forms and Drive.
About 3.5 years of building and running GAS tools for other departments at a large listed company.
One system I built is used by about 2,700 people and saves each of them about 1 to 2 hours a day.
All sample repositories use fictional data.
